# Vulnerable Flask Labs

This repository contains a collection of intentionally vulnerable Flask-based web labs for practicing web application penetration testing.

## Features
- Designed for educational and research purposes only.
- Labs are organized by vulnerability category with optional difficulty levels.
- Includes sample vulnerabilities such as SQL Injection and Cross-Site Scripting.

## Usage
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the application:
   ```
   python app.py
   ```
3. Navigate to `http://localhost:5000` to view available labs.

## Disclaimer
This project is **intentionally insecure**. Do not deploy it in production environments.
